# agent-workbench

Portable interactive coding workflow for Codex, Claude Code and Google Antigravity CLI. Keep harness knowledge in adapters; shared skills use plain SKILL.md frontmatter and relative references. No Pi adapter or autonomous orchestration.

Read README.md for commands and docs/installer.md before changing ownership or transactions. Run `python3 -m unittest discover -s tests -v` and `python3 awb.py validate` after installer or skill changes. Test mutations only in temporary homes and Git repositories; live installation requires reviewing selected or detected clients and explicit apply. Keep private audit details in ignored `.local/`.
